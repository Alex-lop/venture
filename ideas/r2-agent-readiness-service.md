# Fixed-price "agent-ready your codebase" engagements for Boston startups

**Slug:** r2-agent-readiness-service  |  **Track:** A  |  **Researched:** 2026-08-30  |  **Status:** researched  |  **Origin:** round 2 (asset-suggested)

## One-line pitch
A $1,500-3,000 fixed-price, two-week engagement that turns a 5-50 engineer startup's repo into one coding agents can work in safely — scoped agent instruction files, hooks, guardrail policies, a PR provenance check, a repo context tool, and a before/after benchmark on the team's own tickets — sold to Boston/Cambridge eng leads who have bought Claude Code or Cursor seats and are not getting the gains they paid for.

## Specific buyer

**Title:** VP Eng / CTO / Head of Engineering / staff-eng-acting-as-tech-lead at a seed-to-Series-B company. In practice, the person who signed the Cursor or Claude Code invoice and now owns the "are we getting value from this?" question.

**Company shape:** 5-50 engineers, one to three main repos, GitHub, already paying for at least one agent tool. Below 5 engineers there is no coordination problem worth $2,000; above ~80 they hire the work in-house (see Klaviyo and HubSpot below).

**The exact buyer voice, verbatim** (this is the single most on-target artifact found in this research):

> "Our team heavily uses Claude Code. The problem we have is that agents write code that works but ignores existing patterns. They'll create a new database query instead of using the service class my team already built. They'll put logic in the wrong layer, etc. Each fix is small, but across a team of 8 engineers, it adds up, making the codebase drift over time. We've tried shared CLAUDE.md and multiple markdown doc files but they go stale fast and don't scale well. How is everyone else handling this? Has anyone found something that actually works at scale?"
> — one commenter, Ask HN: How do you keep AI coding agents aligned with your codebase standards?, https://news.ycombinator.com/item?id=47266783, posted 2026-03-05. **The whole thread got 6 points and one substantive reply.**

**Where they read:** Hacker News (Ask HN threads on this exact topic — but see the traction numbers in Risks), the Claude Code / Cursor changelogs, `microsoft/agentrc` and similar repos, LinkedIn eng-leadership posts, Maven course marketing, DX / Jellyfish content marketing. Reddit (r/ExperiencedDevs, r/ChatGPTCoding) is where a lot of this conversation lives but **reddit.com returned 403 to every method in this research pass — see Research log.**

**Where they physically are:** Kendall Square, Seaport, Downtown Crossing. Venture Café Cambridge on Thursdays, AI Tinkerers Boston monthly, MassTLC, and the co-op employer network. See Reachability.

## Wedge

Do **not** lead with "I'll write your CLAUDE.md." That artifact is free (see Incumbents) and the public narrative on it soured in August 2026.

Lead with the **measurement**, because that is the thing no free tool and no busy team produces for itself:

1. **Free 60-minute "agent autopsy."** Client picks 5 recently-merged PRs where an agent did the work. Alex replays each one on the current repo, captures a transcript, and shows exactly where the agent guessed wrong: the reinvented service class, the wrong layer, the raw query. This is the deliverable that maps 1:1 onto Pain #1, it costs $0 to produce, and it is what turns a Thursday-night conversation into a scoped invoice.
2. **Paid engagement anchored on a before/after number** run on the team's own tickets, not a benchmark suite — the client's own tickets, agent-run before and after fences/hooks/scoped instructions, with pass rates and human-fix-minutes captured.
3. **The hooks-and-fences layer is the defensible part**, per Pain #7 and #12: hooks are the least portable piece and the thing generators cannot write for you. Sell enforcement, not prose.
4. **The retainer is justified by tool churn, not by maintenance:** "Claude Code shipped 25 versions in the last 30 days" (Pain #9) is the entire retainer pitch, in the customer's own words.

## Build estimate

There is no product to build. The build is the **sellable machine** around a service.

| Component | Agent-days |
|---|---|
| Repeatable audit harness: replay N merged PRs as agent tasks in a throwaway clone, capture transcripts, diff against what actually shipped, score | 2.0 |
| Benchmark scorer: pass/fail, human-fix-minutes, rule-violation counts; renders a one-page before/after PDF the CTO can forward | 1.0 |
| Guardrail starter kit: portable hook set (pre-commit, pre-push, PR provenance check), fences policy, scoped-instruction skeleton per stack (TS/Node, Python, Go) | 1.5 |
| Landing page + fixed-price scope doc + sample deliverable from Alex's own repos (proof of work, since there are no client references yet) | 1.0 |
| Total | **5.5 agent-days** |

**Reusable assets: Graphene policy files + capsule + why as the audit deliverable; Nemisis as the verification demo; Graft/agentrc as installed tooling; RECOVERY_POSTMORTEM as the credibility artifact.** — the fences/policies/hooks/evidence-capsule work the principal already runs daily is the input here, and the audit harness is the only genuinely new code.

Recurring burn: **$0-15/month** (domain only; Claude subscription and GitHub are already owned). Comfortably under the $40 cap.

## Unit economics

- **Price:** $1,500 (5-15 eng) / $3,000 (15-50 eng), fixed, 50% up front.
- **Delivery:** 12-20 hours per engagement ≈ **1.5 weeks of Alex's entire 12 hr/week budget**. At $2,000 that is **$100-165/hr effective** — good for a junior, and it is the *whole* week, so throughput is **~2 engagements/month at absolute maximum**, realistically 1.
- **Ceiling at full utilization:** ~12 engagements/year ≈ **$24,000/yr**, plus retainers.
- **Retainer:** $200-400/month, ~2 hrs/month. 5 retainers = **$1,000-2,000/month recurring** — but this is revenue Alex controls only as long as the client keeps paying, and it is service revenue, not product revenue.
- **COGS:** ~$20-40 in agent tokens per engagement. Effectively 98% margin.
- **Cash-flow shape:** front-loaded and lumpy. Good for funding a Track-B product (money priority #2). Bad as the primary bet (violates money priority #1: recurring revenue they control).
- **Refund exposure:** the pitch promises a before/after number. If the number doesn't move — a live possibility given Counter-evidence #13-15 — Alex either refunds or delivers an uncomfortable report. Scope the contract as "measurement + implementation," never "guaranteed X% improvement."

## Risks

1. **`microsoft/agentrc` is the whole engagement, for free, from Microsoft.** Description: *"Get your repo ready for AI."* README: *"Score your repo's AI-readiness across 9 pillars and a 5-level maturity model"* (the audit) · *"Produce tailored instruction files, evals, and dev configs via the Copilot SDK. No templates — AgentRC reads your actual code"* (the writing) · *"Evaluate whether your instructions still improve agent responses, and run the check in CI so drift doesn't slip through"* (the benchmark **and** the retainer) · `agentrc batch` = *"Batch across an org"* · `agentrc pr owner/repo` = *"Automated PR for any repo"*. **1,034 stars, 93 forks, MIT licensed, created 2026-01-29, last pushed 2026-08-26** (four days before this dossier). https://github.com/microsoft/agentrc. Any CTO who googles "agent readiness" finds this in one search and asks why they are paying $2,000 for `npx github:microsoft/agentrc`. **This is the single biggest risk and it did not exist eight months ago.**
2. **The deliverable is commoditized several times over.** GitHub search on 2026-08-30: **53 repos** matching "AGENTS.md generator" (top: `trevor-nichols/agentrules-architect`, 123 stars), **129 repos** matching "claude code setup team". Plus three separate Show HNs solving rule-file sync alone: Agentfile (47389968), DevBox (46430195), AI-Nexus (47138105). Plus `/init` in Claude Code itself.
3. **Anthropic has routed this category to the Big 4.** $100M Claude Partner Network (2026-03-12) with Accenture, Deloitte, Cognizant, Infosys, plus a free "Code Modernization starter kit." Alex is not competing with them for a 20-person startup — but the *category vocabulary*, the free playbooks, and the "who do I call about this" reflex are being set by firms with nine-figure budgets.
4. **Credibility asymmetry is severe.** The buyer is a CTO with 10-20 years of experience. The seller is a 20-year-old junior with no employment history, asking to be trusted with guardrails on the company's production repo. The Maven comp ($699) is sold by an *"ex-AWS GenAI architect"*; the HN consultant answering these threads has *"18+ years shipping"* and *"Key tech lead on Amazon Fire TV launch"* in that bio. Alex's counter is a live demo, and only a live demo.
5. **Repo access is the deal-killer nobody mentions until the contract.** This engagement requires source access to a startup's crown jewels, granted to an unaffiliated individual. Expect NDA, expect security review, expect some fraction of deals to die there — and expect it to add days to a two-week engagement.
6. **Demand intensity is low even where the pain is real.** The Ask HN threads that state this problem most clearly got **11, 6, 2, 2, and 1 point**. Nobody advertised AI-coding-enablement services in the **August 2026 HN "Freelancer? Seeking freelancer?" thread** (15 comments, checked in full). An Indeed search for Boston jobs mentioning Claude Code/Cursor enablement in the last 30 days returned **zero results**. People complain; almost nobody is visibly transacting.
7. **The asset depreciates faster than it can be sold.** "Claude Code shipped 25 versions in the last 30 days" (Pain #9). A playbook handed over in October is partly wrong by December. That is a retainer argument and a reputation risk in the same sentence.
8. **The public narrative turned skeptical mid-research.** "Your AGENTS.md file doesn't do anything" hit HN on 2026-08-28 — two days before this dossier — with 26 points and 33 comments, and the thread consensus was that these files are small routers, not the load-bearing artifact.
9. **Zero recurring revenue Alex controls.** Against the stated money priority, this is a #2 idea (one-time revenue that funds #1), not a #1. Every hour is sold once.

## Kill criteria

Kill or hard-pivot if any of these is true:

- **After 4 Venture Café Thursdays + 1 AI Tinkerers night + 10 co-op warm intros (≈30 days, $0 spend), fewer than 5 eng leads accept the free 60-minute agent autopsy.** Reachability is this idea's best score; if the free offer won't convert in the densest possible room, nothing downstream will.
- **Of those free autopsies, zero convert to a paid engagement within 30 days of delivery.** The autopsy is designed to be the closer; if it doesn't close, the price is wrong or the pain isn't budgeted.
- **Two or more prospects independently say "we'll just run agentrc."** That is the market telling you the deliverable is free.
- **The first paid engagement's before/after benchmark shows no measurable improvement.** Then the product doesn't work and the refund obligation is real.
- **First engagement takes more than 25 hours** (>2 weeks of total capacity). At that point the effective rate collapses and it is a job, not a business.
- **Repo-access/NDA friction kills 2 of the first 3 deals.** The sales cycle is then too long for a 12 hr/week solo operator.
